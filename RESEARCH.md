# Open experiments and decisions

## Next Studio experiment

**Next Studio run: create a qualified specialist for the block-27 transplant.** Three diagnostics have shown how easily an off-the-shelf donor can look complementary without supplying a necessary skill. Use the existing 0.5B coding donor and a development-only, executable task to train its final feed-forward subnetwork as a specialist. The original indentation panel is already observed discovery data. Freeze a new protocol with fresh, structurally disjoint train, validation and test families before scoring. Give the native 1.5B host the same labeled examples and a matched adaptation budget; also record the raw host and the cheap executable solver. Require a replicated solve advantage on validation that survives a donor-local intervention: revert **only the expert weights intended for transfer** inside the donor and identify the solves it loses. If either qualification fails, stop before transplanting. If both pass, transplant that frozen subnetwork via the established block-27 interface, train only host block 28 with the matched arms and score new solves with the donor on and off. Separate the value of donor specialization data from an advantage in the transfer mechanism. A single qualified, demonstrably causal donor answers more than further unguided task screening.

**Frozen-donor screen closed.** On four-way indentation repairs with all candidates compiling, the host solved 64/256 and the donor 63/256. The host always chose four spaces, and the donor's answer was unchanged in 59/64 counterfactual quartets. No validation, test, or new graft was run after this failed discovery screen. **Wall result.** A 129-parameter local controller reading both ends recognized the hidden crossing rule on 681/681 affected held-out open/sealed pairs for every seed. Removing its far latch throughout training and scoring left the matched control with 98.76% ordinary accuracy and 0/681 paired successes. The exact graph interpreter tied the learned gate. Retire further door-size or orientation sweeps. The learned gate is available as a specialized donor if a matched, fully observed host proves meaningfully weaker. ## What opens the other paths

- **Expert surgery.** The off-the-shelf coding donor's semantic validation lead over a task-trained host was below the prespecified threshold and disappeared on final test. A specialized donor with a demonstrated advantage on an unsaturated task would justify another transplant. The small trained spatial write controller offers an auditable donor whose input-output rule is independently verifiable. First check whether a matched fresh controller can relearn the rule at the same budget. [Semantic qualification](https://github.com/buildngrowsv/routed-expert-splice/tree/d2062a8f88e4bb82f12c442461cd1bf601dd69dd/semantic)
- **Routing.** A confidence-based second call and a partial-verification cascade both lost to a cheaper endpoint on their respective panels. Reopen when a cheap per-example signal predicts incremental value over the strongest single-model or execution-only control. Measure prospective compute as well as solve counts.
- **Walls and geometry.** The learned local read rule obeyed a supplied wall with one doorway. The hidden-door controller subsequently learned the entire binary endpoint rule. Reopen with a change that requires information beyond those six readings and a matched fully observed baseline.
- **Learning 3D from views.** Internal 3D wiring and data-driven 3D reconstruction are separate empirical questions. Image-only supervision already recovered depth on ambiguous synthetic quartets given camera geometry, and a cheap fixed matcher did better. Reopen for an input that disambiguates currently hidden surfaces or for a new domain in which the simple geometric control fails. Do not spend a run tuning width on this renderer.
- **Scale.** Increase volume or depth only where doing so discriminates two accounts. Depth extrapolation exposed instability that a wider grid left hidden. A full-volume benchmark should report voxels, transitions, active channels, peak memory, and elapsed seconds.

## Latest public evidence

The preceding bank-role round used 500 updates for each of nine primary fits plus one calibration fit. The neutral models showed 1.25 percentage points of selective disruption, below the 25-point criterion, and an unannounced bank exchange reduced their exact-word accuracy further. GPU reloads reproduced all published counts. [Counts, curves and compute](learned_banks/results/summary.json)

The trained fixed and convex-write arms both reproduced every word on the new static-reference panel. Disabling the SAVE gate erased all correct words on save-dependent cells. When the explicit token was removed, replacing the relevant neighbor signal reduced exact recovery from 100% to 36.32%, while replacing an irrelevant signal preserved 100%. The broader research claim remains bounded by the built-in topology, state split and synthetic rule. [Study and fixed evidence](spatial_references/README.md)
