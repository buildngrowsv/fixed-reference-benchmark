# Does a protected early reference help a transformer track mutable records?

Train a causal transformer from scratch on streams of record updates. Each example has sixteen registers, with 32 possible values. The initial register/value records appear in shuffled order. Later events change values and ask for either the initial or current value of a named register. Query labels never appear as input. Only answers to queries enter the loss. Use matched program streams, identical weight initialization and query heads. Compare a 64-channel exact reference to block 2, protected through blocks 3–7, against a writable reference with identical initially zero write projections. Block 8 is unrestricted in both. Every model sees the full causal prefix. A correct interpreter and always answer with the initial value set the controls. Primary evaluation uses queries whose current and original values differ, weighting the two query types equally. Report each type, exact counts and costs.

Eight blocks, width 384, six heads, fourfold MLP expansion. Sequence length 256 (each event occupies four tokens), batch 32, 4,096 updates per arm in the main paired comparison. Use AdamW, warmup and clipping, identical training seed 101 and no checkpoint selection. First train both arms for 512 updates and save resumable checkpoints. Advance to 4,096 if at least one arm beats uniform chance by ten points on the 512-update validation panel for the mean of original and current at changed registers. Otherwise close this budget and diagnose the task. Training and publication can overlap; the rest of the queue advances independently. Save checkpoints at least every 32 updates and report throughput to estimate remaining wall time from the device itself.

Use independent locked validation and final panels. At the final checkpoint, alter one initial register value in an otherwise identical program, with at least one later overwrite, and score original and current answers separately. At the entrance to block 8, replace only the 64 candidate channels with the matched counterfactual program's values. Keep the rest of the recipient state unchanged. Quantify both lost and rescued answers; compare with the equivalent intervention on the writable control. Run an independent paired training order only if the main clean held-out difference is at least two points in magnitude and its paired program-bootstrap interval excludes zero on validation (locked final outcomes never govern replication). A simple interpreter is the performance ceiling. Parameter count and training budgets distinguish this scale from the earlier narrow board tasks.
