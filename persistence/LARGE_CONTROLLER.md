# Did 468 shared weights limit the emergence of separate spatial memory roles?

The role-neutral persistent controller recovered 1,071 of 18,544 words on the original test. Giving the same model a prior preference for working and snapshot roles recovered every word. Reopen that result with 57,812 learned weights. Keep the two 32-value banks, 14 neighbor read ports, eight commands, eight observable sensor bits, and the original rollout and target generator. Add a learned 2-by-14 routing correction for each of the 2,048 command/sensor combinations. Start all corrections at zero. This increases the expressiveness of the local rule and retains the small models’ initial transitions. It is a categorical local router. Weight count and parameterization both change.

Train a symmetric persistent start and a role-biased positive control on the original seed-101 batches: 500 Adam updates on 4³ cells over eight steps. Choose the bank associated with memory using validation alone. On the same held-out 6³ cells over 16 steps compare exact 32-bit word accuracy against the archived small models and exchange each bank across paired volumes. Require at least 90% large symmetric word accuracy, a positive lower paired bound for improvement over the small persistent controller, and a selective disruption of at least 25 points for the validation-selected bank. On success only, evaluate both models on 16³ cells over 32 steps. A failure on the biased control weakens any interpretation about neutral learning. The first comparison changes learned capacity at fixed grid size; the 4,096-cell follow-up measures spatial and temporal extrapolation separately.
