# Does the compact model need the early reference?

Compare a sealed bypass with an equally narrow middle network that can fill its 64 exit slots from the current stream alone. Both store 26,830,464 parameters, share initial tensors, and run seven 448-wide blocks between identical 512-wide entrance and exit stages. In the control, the last block receives all 448 current features and a second copy of their final 64 coordinates. In the sealed model the last 64 come from the exit of block 2. No new parameters or projections are introduced. The duplication makes some linear inputs redundant, so nominal parameter matching does not imply equal effective rank. This is a test of whether transporting the early signal helps at this bottleneck. It is one particular no-bypass control.

Use the same seed 101, training order, package splits, optimizer, timing and checkpoint schedule as the finished or running sealed model. Compare with archived sealed and full-width readable checkpoints on exactly the same windows. At 4,096 updates, proceed to 16,384 if the upper paired validation penalty of the working-only exit versus sealed is at most 0.05 bits per byte. A larger loss already diagnoses a practical difference at the screening budget and closes the longer fit. At full budget report paired package intervals for working-only minus sealed, byte top-one accuracy and per-window scores. Call an early-reference advantage material only if the lower 95% test bound is above +0.02 bits per byte. An upper bound below +0.02 supports an equally compact alternative within that margin on this training seed. Fixed full and writable are archival context. One corpus and initialization limit the inference.
