# A 238M model carrying a sealed copy qualified for held-out training

On the same 1,024 CPython validation windows after 4,096 updates, the 285M readable reference scored **1.02025** bits per byte. Narrowing seven middle blocks and restoring 192 untouched early values at the end reduced stored weights by 16.31% and scored **1.02273**. The paired interval for sealed minus readable was −0.00301 to +0.00645 bits per byte, within the +0.02 screen margin. At the same 238M size, filling those exit coordinates from the current state scored **1.01453**. The early copy was worse by 0.00820 (paired 95% interval +0.00363 to +0.01029).
