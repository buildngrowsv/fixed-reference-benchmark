# Does a narrower model keep its accuracy after the Python codebase changes?

The sealed 26.83M-parameter model preserved the full readable model’s predictive quality within 0.02 bits per byte on CPython. Test that resource claim on unrelated source projects before and after further training. Fix both completed seed-101 CPython checkpoints, reset AdamW identically, and give both models 8,192 updates of 8,192 bytes with the same project, file and window at every step. Adapt on NumPy, SciPy and Matplotlib. At each update sample one of the three uniformly, then sample windows uniformly among its eligible byte offsets. Use a 128-step warmup to 0.0002. No hyperparameter selection uses downstream scores.

Before and after adapting, evaluate the same 512 byte windows per project in pandas, NetworkX, xarray, seaborn, mpmath and joblib. This is a fixed panel of six third-party projects. Pin source releases and archive SHA-256, use only package-directory Python files of at least 513 bytes, exclude listed test and vendor directories, and remove exact file duplicates against eligible CPython files and previously scanned projects. Record files, identifiers and offsets for reproduction. Near duplicates and shared idioms may remain. Package code is read as bytes. Each project gets equal weight in the primary mean. Resample files as clusters within each fixed held-out project, and keep the model predictions paired. Report the sealed-minus-readable point estimate for each project, the macro contrast and its 95% interval, both absolute losses, and change on the original CPython test windows. Success requires a post-adaptation upper bound below 0.02 bits per byte plus a point difference below 0.02 in at least five of six projects. A failure narrows the original efficiency claim to CPython. Different numerical-library projects, repeated exposures and initialization from one training order limit generalization. No comparison to a duplicate-coordinate exit is implied. At observed speeds the paired run takes roughly ten to thirteen minutes.
