# Does the early copy help beyond the repeated coordinates in the compact control?

The no-bypass comparator repeats 64 coordinates that already enter the final block. Its first training order cost 0.00888 bits per byte against the sealed reference. Test whether this small difference reflects a particularly weak choice of final inputs. Use the absolute values of those same 64 final working coordinates. Their signed values already appear in the other 448 inputs. The added coordinates now expose a nonlinear feature, introduce zero learned parameters and leave the squared norm at the entrance to the last block identical to duplication for any fixed working state. Both compact controls have access to precisely the same information. The early-reference arm gets a separate state computed seven blocks earlier.

Train one new 26,830,464-weight model from scratch, using the same initial weights, seed 101, 16,384 updates, bytes, checkpoints and AdamW configuration as the two controls. Verify numerically on identical single-example working states that duplication and magnitude give the same per-token RMS and can give different model logits. Score archived held-out validation and test windows on all three arms. The primary comparison is magnitude minus sealed with a package-paired 95% interval. If the upper bound is below +0.005 bits per byte and magnitude also beats duplication with an upper bound below zero, conclude that these final-state features recover most of the original small penalty at this precision. If the lower bound exceeds +0.005, conclude that the earlier features retain a measurable advantage over this stronger no-bypass control on this training order. Otherwise leave the mechanism open. No further feature-map search follows an ambiguous result. Measured Studio training time for this single fit is roughly ten minutes.
