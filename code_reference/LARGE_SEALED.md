# Does sealing a 192-value early reference justify a narrower network?

The original 26.83M-parameter sealed model used 16.13% fewer weights than the readable model and retained similar accuracy on CPython and six external Python projects. Its equally compact late-copy control retained most of the benefit. Scale this specific architectural comparison after both wide baseline arms demonstrate basic learning on CPython.
