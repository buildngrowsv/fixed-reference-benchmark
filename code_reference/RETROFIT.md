# Can a trained model acquire a useful fixed reference without retraining?

Earlier experiments trained a fixed reference into the model. Start here with the 285M writable model at update 4,096, where it already scores 1.01431 validation bits per byte. Keep all weights frozen. Choose one eighth of the residual channels using only unlabeled activation statistics on CPython training windows. After each of seven middle blocks, replace the chosen channel values with their exact values at the exit of block 2. The middles can work with that copy and update their other channels. The final block is unconstrained. This tests an intervention on the model’s activations with its ordinary compute budget. [Recovered checkpoint](large_study/recovery/README.md)

## Is there room to impose a tunnel after training?

Collect per-channel early RMS and the mean squared change from block 2 across the seven middle outputs on 128 training windows. Divide drift by the mean squared early activation with a small numerical floor. Split channels into sixteen groups by early RMS. Select the lowest-drift eighth in each group. Sample the same number of different channels per group as the control, using a fixed seed. This keeps the RMS strata and number of channels matched. Choose groups, the fraction and all panel seeds in advance. Compare an untouched forward pass, the selected freeze and the random freeze on 512 fresh validation windows. The exact offsets differ from previous validation samples. Require the upper package-paired confidence bound for selected minus native loss to be at most +0.03 bits per byte, and require a positive lower bound for random minus selected loss. Preserve the channel assignments and scores. This asks whether the existing trajectory has a subset that tolerates being made fixed. Whole-layer skipping and activation patching have precedents. Our intervention keeps all layers active and changes only one eighth of each middle output. ## Can those same channels transmit a counterfactual?

Generate 512 new pairs of executable Python functions at generator indices 8192–8703. Each pair differs in an early variable name by one letter. Ask the model for the final letter at the return. For each frozen-channel condition separately, replace the block-2 copy with its partner’s copy while the rest of the program keeps its own block-2 state. The borrowed values enter before block 3 and are restored after each middle block. On pairs where both clean frozen models initially prefer both correct answers, count both predictions switching to the partner’s specific letter. Require at least 100 eligible pairs, five points more swaps in the selected arm than in the random arm, and a positive lower paired bound. This secondary result can distinguish tolerating a constraint from using the transferred values to answer. Require both the loss and swap gates to justify adapting this intervention to a larger checkpoint. Record the clean result on each arm, including when there are too few eligible pairs.

The 32M preflight uses 16 short calibration and validation windows and eight separate program pairs. It checks the actual checkpoint, forward path, saved audit format and exchange. Its sample is descriptive. The registered 285M run uses the complete 512-byte windows. The 285M training run processed about 42,600 bytes per second. Allow a few minutes for this shorter inference-only test and its checkpoint load.
