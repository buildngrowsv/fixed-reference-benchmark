# Add the tunnel after training

Can we make part of a trained model’s working state read-only and use those values to carry an earlier fact? Start with a writable Python predictor. Select the one eighth of its channels that change least relative to their usual size, then copy those channels from block 2 through seven middle blocks. Compare against the original predictor and a random set of channels of similar size. No weights are updated. [Full protocol and decision thresholds](../RETROFIT.md) · [Run code](../retrofit.py)

The 32M checkpoint preflight ran on the Studio’s CPU. It checks that the untouched scoring path reproduces the original model exactly and that both freeze conditions produce valid predictions. On 16 short CPython windows the original, low-drift and random conditions scored 1.409, 1.452 and 1.455 bits per byte respectively. On seven identifier pairs both frozen conditions got right, swapping the copied values caused zero flips to the other program’s correct answer in either condition. This small preflight checks the intervention and its evidence format. The queued test uses the 285M checkpoint, 192 channels, 512 full CPython windows and 512 fresh program pairs.
