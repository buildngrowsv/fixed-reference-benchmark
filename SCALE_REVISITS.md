# Which small-model results survive a larger network?

| Question | Earlier evidence | Larger test and first decision |
|---|---|---|
| Does one routed head retrieve memory? | 14.3M weights, 92.26% routed and 8.85% dense | At 227M, 4.05% and 3.03% under the same short budget. The original-rate dense continuation became unstable. At one quarter rate and 4,096 total updates the routed model scored 3.69% and the dense model 3.08%. [Continuation evidence](register_routing/budget_study/README.md). [Width study](register_routing/large_study/README.md) |
| Can a host learn around a small expert? | A 261K-weight student delivered 90.29% recall in the small hybrid. | In a 227M recipient, only 4 of 333 new solves vanished with the donor off. Require evidence that the recipient uses the signal before enlarging the expert. [Graft evidence](register_routing/large_study/README.md) |
| Did a small local controller prevent separate spatial memory roles? | The 468-weight neutral rule recalled 5.78% of complete words. | At 57,812 weights, 6.72%. The role-initialized control retained 100%. The extra capacity bought 176 words out of 18,544. [Spatial memory study](persistence/large_study/README.md) |
| Can a fixed forward reference help predict real Python? | At 32M weights, the fixed and writable arms were 0.00197 bits per byte apart. | At 285M with 192 reference coordinates, fixed and writable scored 5.737 and 5.079 validation bits per byte. A byte-frequency control scored 4.547. At one third the learning rate the two arms reached 1.02025 and 1.01431 and qualified for a held-out test. Final test losses were 1.08992 fixed and 1.08005 writable. [Held-out evidence](code_reference/large_study/held_out/README.md). [Optimization recovery](code_reference/large_study/recovery/README.md). [Paired width result](code_reference/large_study/README.md) |
| Does a physically sealed tunnel justify making the intervening blocks narrower? | The 26.83M sealed model kept most of the 32M model’s accuracy. An equal-size late copy did nearly as well. | Compare a 192-value sealed copy with an equal-size late copy inside two 238M models. Both share a 285M readable baseline. The recovered baseline qualified the paired short validation run at its matching learning rate. [Sealed tunnel protocol](code_reference/LARGE_SEALED.md) |
| Does a pretrained coding donor outperform a larger host on complete code repairs? | The 0.5B coding donor solved 7 of 256 whole triplets, the 1.5B host solved zero, and the graft solved zero. | The 7B coder beat the 14B host 49–0 on qualification and 54–0 on fresh groups. Its block-27 transplant solved 0/256 after training host block 28. The trained native host solved 2 and the shuffled donor solved 13. Donor removal rescued two groups. [Transplant and removal ledger](https://github.com/buildngrowsv/routed-expert-splice/tree/main/nested_surgery/large_graft_study). [Scores and raw logits](https://github.com/buildngrowsv/routed-expert-splice/tree/main/nested_surgery/large_opener_study). [Qualification protocol](https://github.com/buildngrowsv/routed-expert-splice/blob/main/nested_surgery/LARGE_OPENER.md) |

The hidden-door controller and its exact graph interpreter already tied on the available crossing rule. A harder rule would make another size comparison informative there. In the two-view depth study, the fixed geometric matcher already beat the learned model on the current renderer. A new visibility or image-distribution challenge would give a larger learned model room to demonstrate an advantage.
