# Which small-model results survive a larger network?

| Question | Earlier evidence | Larger test and first decision |
|---|---|---|
| Does one routed head retrieve memory? | 14.3M weights, 92.26% routed and 8.85% dense | At 227M, 4.05% and 3.03% under the same short budget. The dense continuation became unstable. Continue with a smaller update size in both arms. [Width study](register_routing/large_study/README.md) |
| Can a host learn around a small expert? | A 261K-weight student delivered 90.29% recall in the small hybrid. | In a 227M recipient, only 4 of 333 new solves vanished with the donor off. Require evidence that the recipient uses the signal before enlarging the expert. [Graft evidence](register_routing/large_study/README.md) |
| Did a small local controller prevent separate spatial memory roles? | The 468-weight neutral rule recalled 5.78% of complete words. | At 57,812 weights, 6.72%. The role-initialized control retained 100%. The extra capacity bought 176 words out of 18,544. [Spatial memory study](persistence/large_study/README.md) |
| Can a fixed forward reference help predict real Python? | At 32M weights, the fixed and writable arms were 0.00197 bits per byte apart. | At 285M with 192 reference coordinates, fixed and writable scored 5.737 and 5.079 validation bits per byte. A byte-frequency control scored 4.547. The original gate closed; a lower-rate, same-data recovery is queued. [Paired width result](code_reference/large_study/README.md) |
| Does a physically sealed tunnel justify making the intervening blocks narrower? | The 26.83M sealed model kept most of the 32M model’s accuracy. An equal-size late copy did nearly as well. | Compare a 192-value sealed copy with an equal-size late copy inside two 238M models. Both share a 285M readable baseline. The paired short validation run depends on the wide baseline reaching basic competence. [Sealed tunnel protocol](code_reference/LARGE_SEALED.md) |
| Does a pretrained coding donor outperform a larger host on complete code repairs? | The 0.5B coding donor solved 7 of 256 whole triplets, the 1.5B host solved zero, and the graft solved zero. | Score the 7B coding donor and 14B general host on the identical 768 executable repairs. Require a net ten-point advantage and at least 25 donor-only triplets before investing in another graft. [Qualification protocol](https://github.com/buildngrowsv/routed-expert-splice/blob/main/nested_surgery/LARGE_OPENER.md) |

The hidden-door controller and its exact graph interpreter already tied on the available crossing rule. A harder rule would make another size comparison informative there. In the two-view depth study, the fixed geometric matcher already beat the learned model on the current renderer. A new visibility or image-distribution challenge would give a larger learned model room to demonstrate an advantage.
