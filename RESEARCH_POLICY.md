# Mac Studio research policy

The active study asks whether a frozen language model can use a value supplied by another model to compute an exact answer on an unfamiliar task. [Flagship protocol](../routed-expert-splice/FLAGSHIP.md)

Parallax, 3D memory grids and moving walls, and the Qwen-72B dictionary-key chain are paused. Retain their receipts and checkpoints. Let any active archival run finish before the hold takes effect.

Queue one comparison at a time. Before adding it, pin the source and specify the main claim, how a positive, null or reversed result would change it, the closest literature and simplest strong baseline, and the budget and stopping rule. An idle Studio is appropriate while the next comparison lacks those requirements.

Keep run details, controls and negative outcomes in one study record. Submit one consolidated paper per completed study with a pinned evidence commit and an independent check. Existing submissions remain part of the record.
