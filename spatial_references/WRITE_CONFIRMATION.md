# Can a writable reference reject false writes while still accepting new ones?

The 4,096-voxel long-hold study protected an early save by thresholding the trained write gate. This comparison makes the memory writable throughout the episode and introduces faulty sensor signals. Test 24 fresh worlds of 32³ voxels over 256 transitions using the three archived controllers. Each voxel has a 32-bit source word. Keep the trained read and movement rules frozen.

Use 16 rounds of 16 transitions. A true write is signaled at transitions 3 and 4 within each round in the selected voxels. It should copy the working state as it was immediately before transition 4. The selection is redrawn independently at each round with probability 0.125 per voxel. A separate fault mask, redrawn at probability 0.25 per 4³ tile, injects two false positive pulses per affected voxel. In one world the pulses are separated (transitions 9 and 11). In its paired world they arrive together in time (transitions 9 and 10). Both worlds have the same true writes, pulse counts, fault positions, source words and movement commands. Decoys and true writes use the same encoding within a tick. Each policy sees the current sensor and, where applicable, one previous gate value. It lacks the generator's clock and fault mask.

Compare a thresholded gate that writes on every positive, a soft gate using the product of two successive sigmoid scores, and a thresholded gate that writes only if both scores are positive. Audit exact 32-bit reads just after true writes and after the fault interval. Compare against a provenance simulation that tracks intended source addresses. Summarize the last eight rounds per world and bootstrap by world, with all checkpoint seeds held together. Confirm separated-pulse tolerance if the thresholded two-tick policy scores at least 95% after true writes and faults and exceeds the single-tick policy by at least 5 points after faults, with a positive lower bound. Call the alternative soft rule competitive under the same stimulus if its shortfall at both readouts is at most 2 points. Use the bundled-pulse arm to measure the cost of faults that imitate the full confirmation pattern. Record compute and memory. This measures the consequences of sensor timing when the grammar of intended writes is supplied.
