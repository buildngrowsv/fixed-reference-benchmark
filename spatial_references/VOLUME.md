# Test an implicit write in a true three-dimensional grid

The explicit SAVE task succeeded, so remove the SAVE token. Keep one target mechanism. Each cell sees a movement/restore command, a binary local sensor A and blue sensors B from itself and six spatial neighbors. The world saves the prior working vector when A at this cell and B at its negative-z neighbor are both set. The gate receives no labels for save events. A single sigmoid applied to eight sensor weights plus a bias controls a convex memory update. Read logits are shared across space and time. Compare only full access with an equal-size signal-deprived control that receives an independent Bernoulli channel instead of the relevant B sensor. All other inputs and the labels remain identical.

Use three paired seeds, 500 updates with batch 12, Adam at 0.08, final-board logistic supervision, width 32 and three true spatial axes. Train on 4 by 4 by 4 for eight steps. Test on 128 fresh 6 by 6 by 6 volumes for 16 steps. Primary endpoint is all 32 signs correct for voxels whose source changes if all saves are suppressed. Evaluate unchanged trained full models with the relevant channel replaced, and with an equally distributed irrelevant channel replaced. Record the learned gate's binary truth decisions on an exhaustive sensor truth table as a diagnostic. A positive result establishes recovery of a synthetic local rule from final targets. It does not establish that the model invented a memory slot or the spatial graph.
