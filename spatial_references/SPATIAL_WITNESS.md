# Does separating two write confirmations help when faults have a spatial shape?

On the side-32 grid, two-tick confirmation failed when false pulses imitated the full true pattern. Add a second sensor at a separately located voxel and compare two chosen separations on a side-64 grid. Use a witness one voxel away along the final axis, eight voxels away along the same axis, and the original temporal-only control. Both spatial arms have the same two input bits and apply the same conjunction. The generator sends legitimate witness confirmations to the matching physical sensor. One percent of intended witness signals are independently absent, with the same absent signals for both spatial arms. Neither policy sees the schedule or the fault masks.

Test eight independent worlds at 256 transitions on all three frozen transport controllers. Keep the twice-positive timing for any false write at the primary sensor. In one world the spatial faults activate exactly one quarter of the 4³ tiles. In its matched world they activate the same fraction of the volume, using 4×4 columns spanning the final axis. The first sensor and witness sensor share the same physical fault mask, so a witness sees a fault if its location lies inside that mask. The two separations are tested with the same mask, initial words, true writes and movement. Redraw masks and intended writes every 16 transitions.

Score exact 32-bit reads immediately after intended writes and after false pulses. Record how often each policy executes a false write. Use the last eight rounds for headline rates, and bootstrap by world across checkpoints. Separation qualifies if the eight-voxel policy beats the one-voxel policy by five percentage points at the later read in the tile case, the lower interval is positive, and the same comparison is within two points for the column case. Both spatial policies must accept at least 98% of true writes. This tests a geometry-dependent defense in a supplied topology.
