# Distinguishing protection from an unstable write rule

The depth-24 primary screen found a roughly 41-point exact-word gap. Writable gates on transport commands learned negative values, which can amplify the stored reference. Commit two tests before opening new panels. First, use the same trained grid and disable its writes only at inference. Train one matched writable alternative with a conventional convex update. Its gate is initialized to zero with a live derivative, then projected to [0,1] after each Adam update. Use the original training inputs, budget, seeds and initial read tables. Compare on 1,024 new depth-24 boards, scoring the same causal subset. If convex writable matches protected within one point, attribute the primary advantage to the write parameterization under depth shift and do not claim general superiority of immutability.

Second, add a physical wall to the forward lattice as an inference intervention. Block reads across both seams dividing the toroidal board into two regions. At one seam only, permit crossing at one doorway. Compare open vs sealed counterfactuals with identical payloads and commands. When a move attempts a blocked crossing it stays put. Measure the fixed router on new depth-24 boards where the expected word changes between the two topologies. Check an explicit port interpreter. The crossing restriction is built into connectivity. This tests composition of a learned read rule with a new topology. It does not ask the model to discover the wall.
