# A forward-only spatial network for restoring and moving 32-bit payloads

Treat depth as time and each layer as a 2D toroidal array of cells. An array of depth eight and side six has 288 locations. Every cell starts with 32 independent signed bits. At each layer a local command selects stay, one of four adjacent cells, or restore the 32-bit source of this location. This tests the original forward reference without loops back to earlier computation. A small shared neural router learns how to translate a local command to a port. A classical interpreter gives exact answers and source provenance for each cell. Commands and payloads vary independently.

Make three deliberate comparisons. A read-only reference can be read at every depth. A writable reference starts identical and can be updated by a learned local write gate. A late-only reference can be read on the final layer. The same initial payload enters working state for all three. Use identical router initialization, batches, supervision and three training-order/initialization seeds. Apply the loss only at the final board. Report whole-payload success and bit accuracy on cells for which an intermediate restore causally changes the required source and the final command is not restore. Also score direct initial-copy and execution of the known commands. Swap the memory across held-out boards while retaining each board's commands and initial working state.

Train for 400 updates, batch 24, on side six and depth eight. Evaluate at the training shape, at depth 24 with side six, and at side ten with depth eight on 256 newly generated boards per condition. The primary test is the fixed-minus-writable whole-word difference at depth 24, with paired board/seed uncertainty. A win over late-only identifies the value of access during computation. If neither ordinary learned route works, inspect validation action accuracy before adding models. As an inference diagnostic, discretize the learned routing decisions with argmax to test whether accumulated soft mixing caused any length-related errors. This lattice imposes local communication. A radius-one move may cross a spatial boundary only through its neighborhood; it does not model physical tissue.
