# Can a spatial gate infer where regional boundaries move?

The 96³ regional study used eight supplied regions and recovered more memory when fault direction differed between them. Reuse the same 96³ grid, 32-bit words, 256 transitions, three frozen checkpoints and one witness per write. Compare three methods. Fixed routing uses the original eight regions. Inferred routing estimates where their three pairs of parallel boundary planes lie. The known-boundary control uses the real shifted regions. Every method selects a confirmation axis with the same co-activation statistic from the previous primary detector field and restricts its witness to a distance of eight cells inside its chosen region. The detector is shared and frozen.

Use eight paired worlds with the original pattern of independent column masks in eight 48³ regions. The first configuration places the partitions at their original boundaries. The matched configuration rolls the physical fault field by a fixed, independently drawn displacement on each axis, with each shift selected from multiples of four between 4 and 44 cells. The initial words, transport, exact underlying generated masks, hidden orientations and legitimate writes are paired. As before, legitimate confirmation signals are available in all directions subject to a shared one-percent dropout. The original grid is periodic, so a boundary at position s is paired with its opposite at s+48.

For each candidate boundary pair, take the mean binary activity disagreements across each plane in the previous detector field and add the two scores. Infer each boundary offset by maximizing that paired score. The routing rule then computes candidate co-activation inside the estimated regions. It receives no intended writes, true offsets, future detector activity or saved words. The two-pulse fault offers one prior detector field before the write decision. The detector measurements and known-boundary comparison are identical beyond the supplied offsets.

Score exact memory after faults and legitimate and spurious write acceptance over the last eight rounds. Report how many true boundaries are recovered exactly and within four cells. Bootstrap paired world totals with all checkpoint seeds together. The prediction is at least a five-point gain over fixed routing on shifted faults with a positive lower paired bound, at most a two-point loss on the aligned configuration, and at least 98% legitimate write acceptance. This tests a supplied half-volume partition family, with its translation inferred from activity. It does not search over arbitrary wall shapes.
