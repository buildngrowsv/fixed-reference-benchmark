# Can a host use the head that carried a counterfactual memory?

The displaced-address model supplied a specific alternate answer when its read value was exchanged. Test the portability of that circuit by moving the first head of block 4 into a weak dense host from the same initialization. Copy its query, key and value rows plus the corresponding output columns. This is 98,304 frozen weights in an eight-block, 14.3M-parameter model. The original representations in blocks 1–3 stay in the host. The transplanted head may depend on a representation that those blocks never learned.

Both hosts receive exactly the same displaced-address wiring. Start from the same dense checkpoint and update only host block 5 on identical fresh batches for 1,024 steps. The two arms differ only in whether block 4 keeps its native head or receives the donor head. On 1,024 new programs, record counts on original and current queries about overwritten registers. Score the whole trained donor for context. After training, replace the transplanted head with the native head while keeping the adapted receiver and its wiring unchanged. A transfer requires a five-percentage-point gain in balanced accuracy over both the trained native-head host and this donor-removed version, with both paired program-bootstrap lower bounds above zero. A failure closes this single-head transplant at this adaptation budget. The benchmark only tests transfer between equal-width models descended from a common initialization. Predicted time is roughly a minute at prior program-training speeds.
