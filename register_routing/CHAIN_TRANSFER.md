# Can the same frozen router help convolutional and recurrent hosts follow two alias links?

Each program has three tables. The first maps a key to another name, and the second maps that name to a register. Both alias tables contain an obsolete and a newer link per key. The final table contains three writes per register. A query asks for the initial or latest value of the register reached by following the two current links. Randomly interleave records within each table. Sample alias maps independently of positions and assign 36 or 60 distinct payloads uniformly within each program. This couples name binding, order and retrieval. A symbolic interpreter is exact. Existing pointer networks and multi-query recall establish related tasks. Our comparison is about reuse of one trained locator across host architectures and a longer chain. [Pointer Networks](https://arxiv.org/abs/1506.03134) · [Zoology](https://arxiv.org/abs/2312.04927) · [Earlier one-hop study](address_study/README.md)

Reconstruct the original seed-101 one-hop router from its pinned generator, initialization, 768 training batches and objective. Before new fits, require exact agreement with saved position and answer predictions on all 1,024 original long programs. Freeze the router and call the same weights at each hop and for the final lookup. Feed each call only key symbols, ordinal positions and the operation. Compose the three sets of soft position weights by matrix multiplication. The router sees link destinations as name symbols, and has no access to the final values. The shared architecture exposes table boundaries and the number of hops. Neither equality masks nor address or path labels enter neural training. The donor receives one-hop supervision alone.

Use two genuinely different payload hosts. One embeds the final write values and encodes them with a two-layer temporal convolution. The other embeds them and uses a gated recurrent unit. Each applies the same composed read weights to its independently initialized value representations and uses its own readout and disjoint value vocabulary. The target budget is 128 identical batches of 64 programs per arm within each host/seed. Compare a frozen transplant with two native controls. One learns the identical shared locator end to end from scratch. The stronger comparator trains an independently initialized locator on the exact same 768 one-hop source batches as the donor, then allows that locator to adapt jointly with the host under the same 128 target updates. Both controls route through the same interface with the same parameter count. Run two independent host draws, keeping the same donated weights in all four graft fits. Record fitted parameter counts, timing and paired predictions.

Train on 12 keys per table with 24 link records and 36 write records. Test 1,024 held-out programs per draw with 20 keys, 40 link records and 60 write records. Draw new random alias maps, schedules and payloads from the same key alphabet and report the familiar-length panel for diagnosis. The primary endpoint is held-out answer accuracy (%), paired over programs. A convincing advantage requires a gain of at least three percentage points with a positive 95% lower paired bootstrap bound in each of the four host draws, against both native controls. This is a competitive sample-efficiency test with a matched one-hop source budget for the stronger control.

For the graft only, roll the final read weights seven positions with host weights fixed. For each clean program take the initial/latest query pair for one alias and edit only the destination of its current first link. Choose another valid destination that changes the destination register. The host's payload table stays fixed. As a matched control, apply the same edit to the obsolete first link. Report end-to-end changes conditional on clean correct answers and the unconditional counts. Require both causal success proportions of at least 90% and a positive paired lower bound against rolling in every fit for a positive portability claim. A comparison-narrow or control-failing result is retained with the failed criteria. No checkpoints or repeated scratch datasets are needed.
