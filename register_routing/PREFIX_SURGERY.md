# Does the memory expert need the upstream representations that wrote its input?

The isolated donor head improved balanced accuracy by 3.23 points over the trained native-head host, below the five-point transfer threshold. The whole donor scored 92.08%. The direct transplant consumed the host’s activation at block 4. Test whether supplying the head with its original upstream computation restores access to the donor skill.

Keep all host computation and train only host block 5 as in the original surgery. Alongside the host process the same tokens with frozen donor embeddings and the first three donor blocks. Compute the donor head’s 64-dimensional attention output with its original input normalization, query, key and value matrices and displaced addressing. Insert only that output as head 1 in host block 4, using the transplanted output columns. No other donor state enters the host. Both branches use only the current and preceding input tokens. Extra inference work includes the three donor blocks.

Train one matched sham arm with the same extra frozen computations using the same embeddings and three blocks from their deterministic seed-101 initialization, before donor training. It still gets the trained donor head, its normalization and the identical addressing. Both receivers use identical 1,024 batches, initialization, optimizer and trainable parameters. Compare on the same 1,024 test programs to the prior head-only graft, the equally expensive initial-prefix arm, and the same fitted receiver switched back to host inputs after training. Require at least ten balanced-accuracy points over each with positive paired program-bootstrap lower bounds. This is a benchmark-informed follow-up using the same test panel. A positive result earns confirmation on fresh programs. Neither arm removes the added inference cost. Prior transplant throughput implies a total duration on the order of one minute.
