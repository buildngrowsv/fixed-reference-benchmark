# Does paired edit training improve unseen link edits without sacrificing clean accuracy?

Repeat both payload hosts, both host draws, the seed-101 unfrozen donor, the from-scratch native router, and the independently pretrained native router. Use 128 Adam updates and the original 64 clean base programs per update, with matched initial weights and base streams within each pair. Reproduce all three original clean-only arms as controls. The treatment adds two queries from a counterfactual that changes the current first alias and two from a matched counterfactual that changes the obsolete first alias. Each edit changes one destination and has the same construction as the audited chain test. Train on clean, current-edit and obsolete-edit answer cross-entropy with weights 0.60, 0.20 and 0.20. Add a 0.10 weight on a paired ranking loss. The new value should outrank the old value after a current edit, while the old value should outrank the new value after an obsolete edit. The position and path labels are used only in scoring. There are 128 optimizer updates in both conditions and four extra answer targets per base program in treatment.

Audit replay of original clean predictions in all three controls and original donor edit predictions. The primary panel uses freshly generated 60-write programs from seeds 719991 plus 503 and 607. None enter training. Use 1,024 programs and 16 clean queries per fit, plus two original/latest queries under each edit. Retain the original panel as a continuity check. Require at least 90% in both original conditional edit endpoints and a paired 95% lower bound above a one-point clean accuracy loss relative to the prior clean-only adapted donor in all four donor fits. Report conditional and unconditional counts, paired clean uncertainty and the edit-rate intervals. The one-point clean tolerance is an explicit analysis choice. The literal point change is reported alongside it. Preserve all matched native comparisons even if the donor fails.
