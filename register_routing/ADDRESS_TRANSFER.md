# Can a transplanted attention router find a write without seeing its value?

Boucher's revised November 2026 working paper reports that a graft transferred an already-computed value in its synthetic setting. Here the graft exports one attention-score row per query. It receives two-symbol write keys, the query key, the original/latest request, and candidate positions. Its function has no input for the values at those positions. The recipient keeps its own value embeddings and output head, with a separate payload vocabulary. A successful graft would thus transfer learned location selection across payload vocabularies. Associative recall, activation grafting and modular retrieval have precedents. The contribution being tested is their conjunction with a payload-blind causal interface and a crossed, held-out shift. [Boucher, revised working paper](https://git.spboucher.ai/wpai0001_uqo) · [Arora et al., Zoology](https://arxiv.org/abs/2312.04927) · [Kim et al., Universal Activation Bus](https://arxiv.org/abs/2608.09521)

## Task and fit

Each example contains randomly interleaved writes to composite keys. The query requests either a key's original or latest write. Give every query scores over all earlier write slots. No equality mask, supplied address, pointer labels, donor answer logits or donated payload vectors enter the graft. Learn the score from task loss. The architecture gives a learned embedding to each component, shares symbol embeddings and learns distinct query and candidate projections, and supplies normalized rank as an input to a learned request-dependent temporal bias. These priors support learning based on content and order. The value is assigned independently and uniformly without replacement within each program, so direct source identification and output accuracy can be scored separately. The program generator stores interpreter addresses for evaluation only. The donor's head predicts classes drawn from IDs 0–63; recipients draw separate payload IDs 64–127 and use their own independent weights.

Training uses 12 keys per program, each written three times, drawn from the 32 even-parity combinations of an 8×8 alphabet. Test an independent panel with 20 keys drawn from the 32 never-trained odd-parity pairs. All component symbols were present in training. The 60 write positions exceed the 36 used to train either router. Test both requests for each of eight keys per program, including pairs sharing their first or second symbol. Report an in-distribution diagnostic as well. The long crossed shift is the primary test.

For each of two independent donor/recipient seed pairs (101/503, 211/607), train a donor for 768 batches of 64. Freeze its locator. Starting from the same recipient initialization, compare three independently fit arms for 128 batches of 64 on exactly the same data and budgets: transplanted locator, a native learned locator with the same architecture, and a frozen untrained donor locator. At test also permute the trained donated logits cyclically along the position dimension while retaining their values and distribution. Keep the recipient readout fixed in this inference intervention. Report correct source argmax, final accuracy, original/latest separately, paired bootstrap intervals at the program level, and exact top-1 and answer ties. Native receives gradient updates for the locator and is an intentionally strong comparator. The goal includes measuring a training-exposure advantage; if native catches up, report both without claiming a gain.

## Counterfactual decision rule

On 1,024 long test programs per seed, change one query-key component while keeping its operation, write schedule and payloads fixed. A matched wrong-component key with a shared symbol is present in the same program. Also change only the request from original to latest for the same key. The predicted address and final answer should both switch correctly. On the same programs, replace only the payload at the interpreter's gold source with an otherwise unused test value. Replace only a stale same-key payload in the matched control. Reuse the same logits, then also check they are bitwise identical under either input change. Primary causal endpoints are a correct replacement answer when the target payload is altered and preservation when the stale write is altered, conditional on the clean answer being correct. Disclose this conditional denominator and report unconditional counts too.

Qualify the location-transfer result only if **each seed** reaches 90% source identification and 90% end-to-end answer accuracy on the long test, a paired 95% lower bound of +10 percentage points over the permutation sham, 80% exact clean-to-counterfactual paired success on both key and time switches, and at least 90% target replacement and 90% stale preservation among clean correct queries. Claim an exposure advantage over native only if the program-paired lower bound exceeds five points in both seeds. These intervals describe test-program variation within a fit. No threshold is changed after observing results.
