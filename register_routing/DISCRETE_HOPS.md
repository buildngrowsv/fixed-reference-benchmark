# Does choosing one record at each hop help the same trained routers?

The final-write study used a soft combination of candidate paths and took an argmax only at the output. After observing its failure to reach 90%, test a single inference change. At each alias table, carry forward only the destination of the highest-ranked candidate. Then select the highest-ranked final write and return its visible payload. The candidate tables, query mode, learned scoring function, weights and training budget remain the original ones. No oracle index enters this inference path. The training paths remain differentiable and are unchanged.

Reconstruct both original hosts and both initialization draws. Include each donor, the independently pretrained native router, and the native router trained from scratch. For each compare the original clean-answer and final-write supervised objectives at 128 updates. Before the new scores, verify the exact final-write and clean-only router predictions on the four archived 2,048-program panels. The new evaluation draws 2,048 fresh programs per host seed from 1688701 plus the original host seed. Score every current and obsolete first-link edit unconditionally. Keep the same no-clean-loss criterion against the clean-only soft-composed direct-read baseline, and report the paired lower bound relative to the preset one-point loss margin. Report each edit rate, its paired program interval, the result when both edit variants must be right for a query, and the result when all four edits must be answered correctly for a program. This comparison was selected after the final-write result. No new evaluation records enter training or selection of routing rules.
