# Does a trained donor branch transfer to a host with a different initialization?

Reuse the same successful seed-101 donor in an existing seed-211 host trained with randomized addresses. This host independently reached 9.61% on its original memory benchmark. It has the same width and vocabulary as the donor, but the starting weights, training examples and prior addressing history differ. A successful transfer here would extend compatibility beyond two networks descended from the same initialization. A failure would leave those differences entangled.

Copy the same donor head into host block 4. Train only host block 5 for 1,024 fresh matched batches in two arms. One receives inputs from the trained frozen upstream donor branch. The other receives the identical architecture and head operating on the seed-101 upstream weights from initialization. Both use the same displaced routing. Score the intact donor, the unadapted native host on this mask, the zero-update trained-branch hybrid, the two adapted arms, and the adapted receiver after replacing the external branch with host input. Use 1,024 fresh programs from seed 436179 and independent training batches from seed 741752. Require balanced original/current recall of at least 75%, an advantage of at least ten points over both the matched untrained branch and the donor-input removal, and positive lower bounds in paired program-bootstrap comparisons. Report the zero-update result and both query types. No other architecture or training budgets will be tuned on this panel. The two short fits should take approximately half a minute.
