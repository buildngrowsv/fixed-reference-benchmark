# Does adapting the exact donated router close the gap?

Repeat the corrected chain-transfer experiment using both original payload hosts and both original host draws. Reconstruct the same seed-101 one-hop router from 768 batches and require exact predictions against the original 16,384-query witness. Initialize two recipient copies with identical host weights and identical router weights. Freeze the 2,306 router weights in one copy. Let the other update them jointly with its host. Train both copies for 128 updates on the same batch order, objective and optimizer as the original. Confirm that the repeated frozen arm reproduces the original clean, rolled, and link-edit predictions. Compare with the already archived native router that independently received matched one-hop pretraining and 128 target updates.

Reuse the 1,024 held-out programs per draw and both corrected single-link edits. Reconstruct the exact same clean and edited gold labels. Report both source and answer accuracy, gains against frozen, residual gaps against pretrained native, 95% program-paired intervals, and the fraction of the original gap recovered. A gain has a positive paired lower bound. A practical closure requires the lower paired bound for adapted donor minus pretrained native to exceed −1 percentage point in every draw. This margin is an analysis choice for this follow-up. Report raw differences and intervals so readers can judge other margins. Reuse the original 90% per-edit bar, counting the correct new answer after a current-link edit and preservation after an obsolete-link edit among each arm's clean correct cases. Also report unconditional accuracy on edits. The long 60-write programs and the 36-write familiar panel stay separate. Weights need not be saved after the audit.
