# Does the stable-address advantage survive a new training draw?

The first coupled training seed gave stable-displaced and freshly randomized addressing 92.26% and 9.06% balanced test accuracy. Before seeing a second result, repeat just that contrast. Initialize both eight-block models with seed 211. Supply the same 512 new program batches and use the same optimizer, batch size and scoring weights as in the published study. Redraw the irrelevant addresses independently of program values with a distinct seed. For the stable arm, shift previous eligible addresses forward by one event cyclically as before. Verify the addressed sets against the original stable implementation and check equal density and causality for the random arm.

Score 2,048 new programs in batches from seed 816239. The primary metric equally weights original and current values on overwritten registers. The paired bootstrap resamples whole programs. Count this as replication if stable displacement exceeds freshly randomized addressing by at least ten percentage points and the lower 95% bound is positive. Retain separate original and current scores, per-program counts and both checkpoint receipts through the single job. There are no hyperparameter changes or additional model sizes. The follow-up independently resamples training initialization and programs within the same task generator.
