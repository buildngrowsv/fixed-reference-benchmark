# Does the transplanted skill depend on the initialization schedule?

Every training program initialized its 16 registers in the first 16 events. Generate 2,048 fresh programs and rearrange independent registers’ events while preserving the order within each register. Randomly permute the first 63 register identities, refill each occurrence with that register’s next event and keep the last event fixed. Event contents, each register’s complete operation trace and correct answers stay identical. An independent register interpreter must recover the same query labels and overwrite status after reordering. This changes positions, distances and neighboring events together.

With all weights frozen, score the intact displaced-address donor, the exact-address donor and the trained-prefix hybrid on both schedules. Invert the permutation before matching the predicted answers to the original events. Recompute allowed causal addresses in each schedule. Use balanced accuracy on overwritten-register queries with program-paired intervals. A lower 95% bound above a five-point loss establishes schedule sensitivity in the hybrid. An upper bound below five points supports robustness at that margin. Otherwise leave the result unresolved. Report the hybrid’s excess loss over exact addressing to distinguish a particularly fragile displaced route from a general schedule shift. This evaluation changes no model parameters and uses no training examples.
