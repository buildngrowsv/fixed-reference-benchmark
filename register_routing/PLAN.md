# Is event addressing the bottleneck in the bottom-up register model?

The 14.3M-parameter writable model missed the prespecified learning threshold after 512 updates. Freeze its budget and program streams. Train the same architecture from scratch with one change in block 4: for the first attention head only, a query-event end marker may read a previous write/initialization end marker with the same register ID or itself. All other head/row pairs retain ordinary causal attention. Register IDs come only from observed inputs. This supplies an explicit routing prior, not the correct answer or a depth-specific target. A cheap interpreter that retrieves the appropriate initial or most recent written value is exact.

Compare against a second fresh fit with an equally sparse attention mask. Within the earlier events of each query, rotate the eligible source positions by one event cyclically; preserve the exact number of permitted reads, self access and strict causality. Rotating among all earlier event positions can change their command types. Also evaluate the archived equally trained writable dense model on the same fresh programs. Match initialization, examples, 512 updates and the 64 initially unwritten channels. Qualify a fresh paired replication only if the matched-register arm beats both the rotated control and archived dense arm by at least five points on validation, with positive lower program-bootstrap bounds. Confirm on an independent panel, scoring original and current values equally on overwritten registers; retain per-program counts. At evaluation, replace correct routing by the rotated mask with the same learned weights as a causal check. If the pilot materially exceeds both controls, replicate the matched-vs-rotated contrast with fresh training seed 211; report the archived dense seed only as a fixed reference. Otherwise stop.
