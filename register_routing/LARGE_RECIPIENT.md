# Can a 261K-weight donor supply answers to a 227M-weight host?

Reuse the frozen student that reproduced the memory signal in the 14.3M host. In the wider host, insert its 64-number output as one head in block 4 without learning a width adapter. Keep the host’s existing 1,536-by-64 output columns in every arm. This tests transfer across host widths. Its interface differs from the earlier equal-width experiment that copied donor output columns. Check native validation recall with the displaced mask before training. If it already reaches 85%, record the ceiling and defer the graft to a harder task.

Otherwise restore the same dense 512-update host for three arms. Train only block 5 for 1,024 fresh matched batches in each, using a native head, the frozen aligned student, or its identically sized shuffled-target control. All arms get the same displaced addressing. Score 1,024 new programs and compare against the unadapted aligned hybrid and the adapted aligned host with its native head restored. Require a five-point balanced advantage over native, shuffled and donor-off, with positive paired program-bootstrap lower bounds. Save each qualifying program/event, target, and native, aligned, shuffled and off prediction. Report newly solved queries that disappear on removal, native solves lost and errors rescued by removal. Retain both checkpoints for a harder follow-up if all arms saturate.
