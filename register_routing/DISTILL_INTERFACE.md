# Can a small learned component replace the donor branch without retraining the host?

The three-block frozen donor branch carried memory into an adapted host with 90.32% balanced recall. Replace the extra donor computation with a width-128, one-block student plus a 64-wide attention read using the same supplied address mask. Train on the frozen donor’s 64-dimensional outputs from 4,096 batches of 32 new programs. The student receives token inputs and the supplied addresses. Gold answers do not enter its objective. Half the mean squared error is averaged over all positions and half over query endpoints. Keep the recipient checkpoint frozen throughout training and evaluation.

Train one identical student from the same initialization and on the same inputs with teacher vectors rotated by one complete program in the batch. This retains the target-vector distribution and disrupts input correspondence. On 1,024 new programs evaluate both students inside the unchanged recipient and compare with its full donor branch. Require a lower paired 95% bound above −5 points for aligned student minus full branch, at least a 10-point advantage over the permuted student with a positive lower bound, and at least 90% fewer learned weights in the branch actually used. Report standalone branch weights excluding the host output projection shared by every arm. Time complete hybrid inference with batch size 32 and 256 tokens on the Studio, after compilation, with synchronized alternating calls. Resource savings on branch weights alone do not establish a speedup of the complete host. The fixed teacher, synthetic task and hand-supplied addresses limit generality.
