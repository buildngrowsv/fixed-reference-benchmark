# Can a frozen doorway detector control a write into protected memory?

Transfer the six-input, 129-parameter both-ends gate trained in the hidden-door experiment. Use the original truth table, but make a positive decision save the current 32-bit word into a private reference. A later read must return the last saved word. All target models observe all six bits under the same fixed permutation. Eight candidate writes per training episode, randomized independent words, final word loss only. A later step with a closed gate must preserve the prior reference. Source supervision is extra information supplied to a pretrained donor.

Pilot on 128 target episodes reused for 120 Adam steps in batches of 32, same data/order and learning rate 0.012. Allow one trainable 6-by-6 linear sensor adapter plus bias, initialized to the identity, ahead of each frozen gate. Compare the released donor (training seed 101), a frequency-matched gate that depends on a different truth table, a smooth hand-coded implementation of the true Boolean rule, and a fresh trainable 6→16→1 controller. The corrupted control uses the same differentiable Boolean interpolation as the hand-coded control; its list of true rows is shuffled with seed 7612. The adapter output is bounded to [0,1] via sigmoid around the binary input. Every recipient shares the same final memory operation.

Selection uses 512 independent pairs at eight writes. In each pair, the final candidate write differs only in the far endpoint latch. One world must save the last word, the other must retain a distinct earlier word. Primary score requires the entire 32-bit answer correct in both worlds. Confirm at sixteen candidate writes on 2,048 new pairs. Report sample-level successes and regressions when the trained recipient's donor is disabled or replaced by the frequency-matched control. Use the same adapter without refitting. Only replicate on two new target-training seeds if the learned donor leads both the fresh and corrupted controls by five points on validation, exceeds 60% paired exact recovery, and the oracle solves every pair. A native tie or a successful analytic control narrows the transfer claim.
